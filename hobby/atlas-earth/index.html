🌎 Atlas Earth

Atlas Earth is a location-based idle game - you buy small parcels of virtual land tied to real-world spots, and each one quietly earns you rent every single second, whether you're watching or not. Plots come in four rarities - Common, Rare, Epic, and Legendary - and the rarer the plot, the better the payout: Legendaries spawn about 10 times less often than Commons, but earn roughly 4 times the rent per second. It's a fun, low-effort hobby, and a good excuse to dig into the data behind it.

p>

The Data

The Atlas Earth dataset started life in a SQL Server database. To make it usable outside of SQL Server - and to feed live reports on this site - I've published it as JSON and CSV files hosted directly from this repo. Power BI can pull either format straight from a URL with its Get Data → Web connector, and anyone can download the CSVs directly for their own tinkering.

🔌 How I Connect Power BI to the Web

In Power BI Desktop, Get Data → Web, paste the URL for any JSON or CSV file below, and Power BI handles the rest - typing columns, refreshing on demand, and keeping the report tied to the live source. When the underlying data changes, one click on Refresh pulls the latest.

Two versions of the database, for anyone curious how it evolved: the Refactored Schema is the clean, final version - just the normalized CREATE TABLE statements with proper foreign keys, ready to build fresh. The Refactor Draft is the original working file - the first-pass tables plus every INSERT statement of my actual plot and passport purchase history, kept as a record of where the data came from and how the redesign got worked out.
