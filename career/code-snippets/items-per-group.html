About This Tool

Handy for whenever you've got a bunch of things - people, tasks, snacks, whatever - that need to be split into a set number of groups, and you want to know exactly how many should land in each one. Enter your total item count and how many groups you need, and it'll tell you how to divide things up as evenly as possible.

How It Works

var items = parseInt(document.getElementById('Students').value); var groups = parseInt(document.getElementById('Teams').value);

Getting started

Grabs the two numbers you typed in - the total number of items, and how many groups you want to split them into.

var smallTeamSize = Math.floor(items/groups); var largeTeamSize = smallTeamSize + 1; var largeTeams = items % groups; var smallTeams = groups - largeTeams;

The actual problem: splitting people evenly

Say you've got 23 items and want 5 groups. 23 ÷ 5 = 4.6 - but you can't have 0.6 of a person on a group. Math.floor() rounds that down to 4, which becomes our "small" group size. But 5 groups × 4 items = only 20 - there are 3 items left over. Those 3 need a home too, so they each get folded into a group that's one bigger (largeTeamSize, which is just smallTeamSize + 1). The remainder operator (%) tells us exactly how many items are left over - and that's also exactly how many "large" groups we need, since each large group absorbs one extra item. Whatever groups are left (groups - largeTeams) stay at the smaller size.

document.getElementById('output').innerHTML = largeTeams === 0 ? smallTeams + " groups with " + smallTeamSize + " items." : largeTeams + " groups with " + largeTeamSize + " items and " + smallTeams + " groups with " + smallTeamSize + " items.";

Showing the result

Stitches the numbers into a plain-English sentence and displays it. For the 23-items-into-5-groups example: "3 groups with 5 items and 2 groups with 4 items" - and sure enough, 3×5 + 2×4 = 23. There's also a special case worth calling out: if the items divide evenly (say, 20 items into 5 groups), largeTeams comes out to 0 - so rather than printing a nonsense "0 groups with ... items" clause, the ternary skips straight to the single even sentence: "5 groups with 4 items."
