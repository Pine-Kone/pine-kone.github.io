Is My Social Security Taxable?

I built this spreadsheet while working as a full-time tax preparer, to make one of the trickier parts of a return easier to explain: how much of a client's Social Security benefits actually count as taxable income. It walks through the IRS's rules and turns what's normally a multi-step worksheet into a few simple input fields.

📗 Download the Spreadsheet

About This Project

Figuring out taxable Social Security benefits normally means working line-by-line through the IRS's own worksheet. This spreadsheet automates that with VLOOKUP and HLOOKUP, pulling the right thresholds and filing-status figures from reference tables instead of looking them up by hand every time. Enter a client's income and filing status, and it hands back the taxable amount.
